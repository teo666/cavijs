cavijs

A TypeScript wrapper around the cavi Rust/WASM physics engine for cables, jacks and plugs — handles cable simulation and mouse interaction, and lets you own the rendering.

Basics

Basic cables — canvas Minimal setup: a few simulated wires drawn by the canvas Renderer. Basic cables — SVG The same minimal setup, drawn by SvgRenderer instead.

Jacks & plugs

Jack & Plug Hand-authored <cavi-jack>/<cavi-wire> markup: drag plugs into jacks to connect and disconnect cables. Custom interaction controller A no-op IInteractionController: shows that jacks and plugs never listen for input themselves.

Patchbay

Modular patchbay — canvas Many jacks laid out by CSS, pre-patched cables of several types, drag-to-connect. Modular patchbay — SVG The same patchbay, wired manually to SvgRenderer.

Zoom & pan

Zoom/pan — canvas (full screen) d3-zoom on a full-screen frame, CSS-positioned jacks, draggable module; cables stay visible at any zoom via surface. Zoom/pan — SVG (full screen) The same zoom/pan setup on SvgRenderer. d3-drag interaction controller A custom IInteractionController built on d3-drag, with several draggable modules under d3-zoom.
