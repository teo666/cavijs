Zoom/Pan, SVG renderer — no x/y attributes anywhere

How it works

Same validation as demo-patchbay-zoom.html, against SvgRenderer instead of the canvas renderer, created with { surface: #zoomFrame } so the svg covers the whole screen and applies the zoom itself. Scroll to zoom, drag to pan. Drag j-c/j-d's dashed box by its header — a plain draggable HTML element cavijs knows nothing about either; its plugged cable stays glued to it via notifyCoordinateTransformChanged(), fired on every drag step instead of every zoom step.
