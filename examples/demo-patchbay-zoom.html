Zoom/Pan, canvas renderer — no x/y attributes anywhere

How it works

Every <cavi-jack> below has no x/y attribute — its position is derived from CSS Grid layout via Jack.getWorldPosition()'s auto-detect fallback. Zoom/pan itself is not implemented by cavijs: it's driven entirely by d3-zoom on the #viewport wrapper, which cavijs knows nothing about — the only thing cavijs is told is the current transform, via setCoordinateTransform/notifyCoordinateTransformChanged, so auto-detected jack positions stay correct regardless of zoom level. Scroll to zoom, drag to pan. Drag j-c/j-d's dashed box by its header — it's a plain draggable HTML element cavijs knows nothing about either; its plugged cable stays glued to it via the same notifyCoordinateTransformChanged() call, fired on every drag step instead of every zoom step. The <cavi-world surface="#zoomFrame"> attribute puts the canvas on the full-screen frame, so cables are never clipped when zooming out and stay sharp when zooming in. See demo-patchbay-zoom-svg.html for the same thing on the SVG renderer.
